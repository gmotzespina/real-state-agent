# Agent Spec: Real Estate Valuation & Bidding Strategy Agent

## Overview
A real estate advisory agent designed for prospective property buyers in Ireland. Given a property listing URL, the agent coordinates two specialist subagents:
1. **Property Researcher**: Fetches and extracts listing details (address, Eircode, asking price, property type, beds/baths, square meters, BER) and queries the Irish Property Price Register (PPR) for historical transactions of the property and comparable sales in the surrounding postal district/area.
2. **Valuation Strategist**: Analyzes the listing price against recent PPR market comparables, determines a fair market valuation range, and synthesizes a tactical bidding plan (opening offer, counter-bidding increments, walk-away ceiling, and negotiation levers).

The root coordinator compiles these findings into a structured buyer valuation and bidding strategy report.

## Language
`python`

## Architecture & Sub-Agents
- **`root_agent` (Coordinator)**: Orchestrates the pipeline, directs user queries, delegates to the specialist subagents, and presents the final consolidated buyer report.
- **`property_researcher` (Specialist Subagent)**: Handles data collection using tools. Scrapes the listing URL for property metadata and queries the Irish Property Price Register (PPR) first by exact address/Eircode, then widening to street or routing key / postal district (e.g. D04).
- **`valuation_strategist` (Specialist Subagent)**: Synthesizes property specs with comparable sales records to calculate fair value estimates and formulate an actionable, staged bidding strategy.

## Example Use Cases
### Use Case 1: Standard Listing Analysis
- **Input**: `https://example.com/property/123-morehampton-road-donnybrook-dublin-4-d04hv00`
- **Output**: 
  - Listing summary: 3-bed terraced house, 110 sqm, asking €750,000, Eircode D04HV00.
  - PPR comps: 4 comparable sales on Morehampton Road and D04 within the past 18 months ranging from €690,000 to €780,000 (€6,500 - €7,100 / sqm).
  - Valuation: Estimated fair value range €715,000 – €745,000.
  - Bidding Strategy: Opening offer at €695,000 (7.3% below asking), increment guide of €5,000, recommended walk-away cap at €755,000.

### Use Case 2: Listing Without Eircode
- **Input**: Listing URL with address "Ballsbridge, Dublin 4" but no explicit Eircode.
- **Output**: Agent extracts street and postal district (D04), searches PPR for "Ballsbridge Dublin 4", retrieves recent sales, flags that exact property history was unverified due to lack of Eircode, and supplies area comps with appropriate wider confidence interval.

## Tools Required
1. **`fetch_listing_page`**:
   - **Purpose**: Retrieves public HTML content of a real estate listing URL and extracts key property attributes (address, Eircode, asking price, bedrooms, bathrooms, property type, size/sqm, BER rating).
   - **API / Implementation**: `httpx` HTTP client with standard browser user-agent headers and `BeautifulSoup` text extraction.
   - **Authentication**: None (public web pages).
2. **`query_property_price_register`**:
   - **Purpose**: Queries the official Irish Property Price Register (PPR) search endpoint (`https://www.propertypriceregister.ie/website/npsra/PPR/npsra-ppr.nsf/PPR-By-Date`) using address/Eircode query strings, county, and date parameters.
   - **API / Implementation**: Performs HTTP GET requests to the PPR search endpoint and parses HTML table records into structured transaction objects (Date of Sale, Address, Postal Code, Price in €, Full Market Price flag, VAT Exclusive flag).
   - **Authentication**: None (public statutory register).

## Constraints & Safety Rules
1. **Financial & Legal Disclaimer**: Every valuation report must prominently state that valuations and bidding strategies are automated algorithmic estimates based on public records for informational purposes only, and do not constitute certified valuations, surveyor reports, or legal/financial advice.
2. **Strict Grounding**: Comps and past sale prices must come exclusively from verified Property Price Register query results or the user prompt. The agent must never hallucinate past sales transactions, dates, or prices.
3. **Transparency**: The agent must state whether the exact property has a recorded past sale or if the valuation relies solely on area comparables.
4. **URL Safety**: The fetch tool must only accept valid HTTP/HTTPS URLs.

## Success Criteria
1. `agents-cli run` successfully executes a listing evaluation end-to-end without unhandled exceptions.
2. Property details (asking price, address/area) are accurately parsed from the provided listing page.
3. PPR query executes with proper query formatting (handling address search and postal code filters) and successfully parses transaction rows.
4. Final output includes all 4 essential report components:
   - Property Profile (asking price, specs)
   - Comparable Sales Table (dates, addresses, sale prices)
   - Fair Value Estimate (range with explicit justification)
   - Actionable Bidding Strategy (entry offer, increment steps, walk-away ceiling)
